# ADR-004: Angular as Frontend Framework

## Date:
2025-11-27

## Status:
Accepted

## Context:
Frontend application requires a user interface to allow users to interact with the existing API endpoints. A modern, maintainable, and scalable frontend framework is needed that integrates well with the existing ASP.NET backend.

## Decision:
Angular will be used as the frontend framework for the following reasons:
- Angular is a popular and mature framework that pairs well with .NET backends
- TypeScript-first approach ensures type safety and better developer experience
- Strong community support and extensive documentation

## Consequences:
Developer needs to learn Angular framework and its ecosystem. This may introduce some initial complexity.
